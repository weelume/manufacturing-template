# Datum · 精密制造

独立 Git 整站模板，协议 git-template 0.2.0。能力、工具链、准备配置、安装、启动、停止与交付见根 README.md。

固定入口：template.json（页面、语言、素材与许可）；project.json（命令、服务、预览与工具需求）；customization.json（实际修改入口）。

规则：docs/ARCHITECTURE.md、docs/CUSTOMIZATION.md、docs/VERIFICATION.md、docs/LICENSE.md、docs/MOTION.md。运行图片与字体均随 public 交付，来源见 docs/ASSETS.json。市场截图仅在 assets 中保存。

默认中文，/en 对应英文；PC、iPad、手机共用同一站点。没有后端、支付、邮件发送、预约持久化或在线授权。阅读资料不触发安装、运行或发布。
